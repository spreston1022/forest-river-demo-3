# Quickstart

## 1. Get your API key

Request access at /subscribe. Once approved, copy your key from /my-subscriptions.

## 2. Make your first request

```bash
curl https://YOUR_GATEWAY_URL/path-1 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## 3. Explore the API

Use the API Reference to browse endpoints and try them live.
