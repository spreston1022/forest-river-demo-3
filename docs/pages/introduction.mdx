Forest River, Inc. is one of the largest manufacturers of recreational vehicles, cargo trailers, and commercial vehicles in North America. This developer portal provides authorized dealer partners and integration teams with programmatic access to Forest River's data and systems.

## What You Can Build

The Forest River API enables dealer partners to build integrations across four core areas:

**Vehicle Inventory** — Query real-time vehicle availability, specifications, pricing, and allocation status across Forest River's full product catalog including camping, work & play, marine, and specialty categories.

**Dealer Management** — Access and manage dealer profiles, allocations, and ordering data programmatically. Integrate Forest River data directly into your Dealer Management System (DMS).

**Order Management** — Submit and track vehicle orders, monitor fulfillment status, and receive event notifications as orders progress through the pipeline.

**Reporting & Analytics** — Pull sales, inventory, and performance data to power your own reporting dashboards and business intelligence tools.

## Getting Started

Access to the Forest River API requires an approved dealer account. To get started:

1. **Create an account** — Click **Sign In** in the top navigation to register using your dealership email address
2. **Request access** — Visit the [Plans](/subscribe) page and request access to the tier that fits your use case
3. **Await approval** — Forest River's partner team reviews all requests within 1–2 business days
4. **Get your API key** — Once approved, your API key will appear in [My Subscriptions](/my-subscriptions)
5. **Start building** — Use your key in the `Authorization: Bearer` header on every API request

## Authentication

All API requests require a valid API key issued through the developer portal. Keys are scoped to your dealership and carry the rate limits associated with your plan tier.

See the [Authentication](/authentication) guide for implementation details and code examples.
